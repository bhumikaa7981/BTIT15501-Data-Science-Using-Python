📚 Part 1 · Matplotlib Foundations

Meet Matplotlib

Python's original, most powerful 2D plotting library — built in 2003. pandas, seaborn, and half the dashboards you've ever seen quietly call it behind the scenes.

PYPLOT STYLE

The disposable camera 📷

Point, click, done. plt.plot() quietly remembers "whatever figure is active right now." Great for a fast look at your data.

OBJECT-ORIENTED STYLE

The DSLR camera 🎥

More to type — fig, ax = plt.subplots() — but full manual control. Ideal once you have multiple charts to juggle.

VIBE CHECK

pyplot is "post it to your story real quick" energy. The Object-Oriented API is "edit it in Lightroom before it goes on the grid" energy. Same photo, different amount of control.

  • pyplot is firing off a Snap with the default filter — gone in seconds.
  • OO API is opening the shot in Lightroom and adjusting every layer before it hits the grid.
  • pyplot is the "chef's choice" at a restaurant; OO is building your own bowl, ingredient by ingredient.
  • pyplot is one quick take; OO is the multi-cut edited version you actually post.
1

Quick Sketch — the pyplot way

import matplotlib.pyplot as plt

weeks = [1, 2, 3, 4]
sales = [120, 135, 150, 170]

plt.plot(weeks, sales)
plt.title("Weekly Sales - pyplot style")
plt.xlabel("Week")
plt.ylabel("Units Sold")
plt.show()

print("Chart created using pyplot's quick-sketch style!")
>>> Chart created using pyplot's quick-sketch style!
  1. Import matplotlib's pyplot module and nickname it plt.
  2. Store the X values (weeks) and Y values (sales) as two lists.
  3. plt.plot() queues up a line joining those points on the "currently active" figure.
  4. title / xlabel / ylabel add context to that same active figure.
  5. plt.show() finally renders everything that was queued.
2

Precise Blueprint — the Object-Oriented way

import matplotlib.pyplot as plt

weeks = [1, 2, 3, 4]
sales = [120, 135, 150, 170]

fig, ax = plt.subplots()
ax.plot(weeks, sales)
ax.set_title("Weekly Sales - OO style")
ax.set_xlabel("Week")
ax.set_ylabel("Units Sold")

fig.savefig("sales.png")
print("Figure object:", fig)
print("Axes object:", ax)
>>> Figure object: <Figure size 640x480>
>>> Axes object: <Axes: title={'Weekly Sales - OO style'}>
  1. plt.subplots() explicitly builds both a Figure and an Axes object — no hidden "current" state.
  2. Every command runs directly on ax, never on some invisible active figure.
  3. OO methods are prefixed with set_ — set_title, set_xlabel, etc.
  4. fig.savefig() writes the exact figure to disk — no ambiguity about which one.
  5. Industry codebases almost always use this style once more than one chart is involved.

Before drawing anything else, learn the names of the parts — you'll use these words in every single chart from here on.

Your first real plot — 24-hour temperature log

import matplotlib.pyplot as plt

hours = list(range(24))
temp = [22,21,20,19,19,20,22,25,28,30,32,33,
        34,34,33,31,29,27,25,24,23,22,22,21]

plt.plot(hours, temp, color="tomato", marker="o")
plt.xlabel("Hour of Day")
plt.ylabel("Temperature (°C)")
plt.title("24-Hour Temperature Log")
plt.show()

peak_hour = temp.index(max(temp))
print(f"Hottest hour: {peak_hour}:00, Temp: {max(temp)}°C")
>>> Hottest hour: 13:00, Temp: 34°C
  1. Build 24 hour labels with range(24), and a matching list of 24 temperature readings.
  2. plt.plot(hours, temp, ...) draws the line and drops a circular marker on every real reading.
  3. Axis labels state the units — °C matters, "just numbers" doesn't.
  4. temp.index(max(temp)) finds the position of the hottest reading in plain Python — no chart-reading required.
VIBE CHECK

This is basically your phone's weather app graph — that little curve that tells you exactly when it'll be too hot to walk to class, without you reading 24 separate numbers.

  • Your phone's hourly weather graph — one glance tells you when to grab a jacket.
  • Google Maps' traffic curve for your commute — the squiggle that says "leave now."
  • A smartwatch heart-rate graph after a workout — nobody's reading the raw BPM log.
  • Netflix's "time watched this week" bar — same idea, way less flex-worthy.
QUICK RECAP

plt.plot() draws. plt.show() reveals. pyplot = quick sketch, Object-Oriented = precise blueprint. Every Figure can hold one or more Axes.

A 1×2 split screen — temperature & humidity

import matplotlib.pyplot as plt

temp_data = [22,24,27,30,32,31,28,25]
humidity_data = [80,75,65,55,45,50,60,70]

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].plot(temp_data, color="coral")
axes[0].set_title("Temperature")

axes[1].plot(humidity_data, color="mediumseagreen")
axes[1].set_title("Humidity")

plt.tight_layout()
plt.show()

print("Number of axes created:", len(axes))
>>> Number of axes created: 2
  1. plt.subplots(1, 2) makes ONE figure containing TWO Axes, arranged in a single row.
  2. axes comes back as a list — axes[0] is the left plot, axes[1] is the right.
  3. Each Axes gets its own .plot() and .set_title() — fully independent of the other.
  4. plt.tight_layout() auto-adjusts spacing so titles/labels never overlap.

A 2×2 grid — comparing 4 tech stocks

import matplotlib.pyplot as plt

stocks = ["AAPL", "MSFT", "GOOG", "AMZN"]
aapl = [180,182,178,190,195,200,198]
msft = [310,315,320,318,325,330,328]
goog = [125,128,130,127,132,135,138]
amzn = [140,142,145,143,148,150,152]
data = [aapl, msft, goog, amzn]

fig, axes = plt.subplots(2, 2, figsize=(10, 7))

for ax, name, d in zip(axes.flat, stocks, data):
    ax.plot(d, marker="o")
    ax.set_title(name)

plt.tight_layout()
plt.show()

print("Grid shape:", axes.shape)
>>> Grid shape: (2, 2)
  1. plt.subplots(2, 2) returns a 2×2 array of Axes objects — four empty plot slots at once.
  2. axes.flat flattens that 2D grid into a simple list, so a normal for loop can walk through it.
  3. zip(axes.flat, stocks, data) pairs each Axes slot with a stock name and its price list — one line fills the whole dashboard.
  4. A quarterly review deck showing all 4 quarters (or here, 4 stocks) in one 2×2 image is a genuinely common real-world layout.
VIBE CHECK

📚 Part 3 · Colors, Markers & Line Styles

Color is a visual language

Four ways to say the exact same color — pick whichever fits the moment: named ('red'), short code ('r'), hex ('#4F9A94'), or an RGB tuple (0.2, 0.6, 0.5).

6

Three ways to specify the same-ish color

import matplotlib.pyplot as plt

x = [1,2,3,4,5]
y = [3,7,4,9,6]

plt.plot(x, y, color="green", label="named color")
plt.plot(x, [v-1 for v in y], color="#4F9A94", label="hex code")
plt.plot(x, [v-2 for v in y], color=(0.9,0.4,0.6), label="RGB tuple")
plt.legend()
plt.title("Three Ways to Set a Color")
plt.show()

print("All three lines drawn with different color formats!")
>>> All three lines drawn with different color formats!
  1. Same x/y shape, offset slightly downward each time so all three lines are visible.
  2. Line 1 uses a plain English name — fastest to type, ~140 names available.
  3. Line 2 uses a hex code — pixel-perfect, the same format used in CSS/design tools.
  4. Line 3 uses an RGB tuple with values between 0 and 1 — useful when colors come from code, not memory.
VIBE CHECK

Exactly like picking a hex code for your Notion page or Canva design — "sage green" vs #87A96B vs the RGB slider are three doors to the same room.

  • Picking a hex code for your Linktree or Notion page background.

  • Canva's color tool: name, hex, or RGB slider — three doors, same shade.

Markers — pinning the exact data point

import matplotlib.pyplot as plt

asia_pop, asia_temp = [30,45,60], [28,27,26]
europe_pop, europe_temp = [15,20,18], [12,14,13]
africa_pop, africa_temp = [25,35,40], [30,29,31]

plt.scatter(asia_pop, asia_temp, marker="o", label="Asia")
plt.scatter(europe_pop, europe_temp, marker="^", label="Europe")
plt.scatter(africa_pop, africa_temp, marker="s", label="Africa")

plt.xlabel("Population (millions)")
plt.ylabel("Avg Temperature (°C)")
plt.legend()
plt.title("Cities by Continent")
plt.show()

print("3 continents plotted with 3 different markers")
>>> 3 continents plotted with 3 different markers
  1. Three groups of (population, temperature) points, one per continent.
  2. marker="o"/"^"/"s" gives each group a distinct shape — circle, triangle, square.
  3. Even printed in black-and-white, the shapes stay distinguishable — color alone wouldn't survive a grayscale printer.
  4. Markers add a third dimension of meaning (category) on top of the X/Y position.
8

Line styles & the shorthand combo trick

import matplotlib.pyplot as plt

months = [1,2,3,4,5,6]
actual = [100,110,105,120,130,128]
forecast_months = [6,7,8,9]
forecast = [128,135,140,150]

# shorthand: color + linestyle + marker in ONE string
plt.plot(months, actual, "bo-", label="Actual")
plt.plot(forecast_months, forecast, "^--", color="orange", label="Forecast")

plt.legend()
plt.title("Actual vs Forecast Sales")
plt.show()

print("Solid blue = confirmed data, dashed orange = prediction")
>>> Solid blue = confirmed data, dashed orange = prediction
  1. "bo-" packs three things into four characters: blue color, o circle marker, - solid line.
  2. "^--" means triangle markers on a dashed line — the near-universal symbol for "not confirmed yet."
  3. Both series share one chart and one legend, so the eye can compare "what happened" vs "what we predict."
VIBE CHECK

Solid line = your actual streak count. Dashed line = the "on track for a 30-day streak" projection Duolingo shows you. Same chart logic, way more guilt-tripping.

  • Duolingo's streak flame (solid, confirmed) vs. the "keep it up" projection (dashed, not real yet).
  • A weather app's actual-temp line vs. its 10-day dashed forecast line.
  • Your banking app's "spent so far" line vs. the dotted "projected month-end spend."
  • A fitness app's real pace line vs. the dashed goal-pace line on the same graph.
REAL WORLD

A mechanical engineer's stress-strain curve colors the "safe" elastic region green and the "danger" region beyond yield strength red — color here isn't decoration, it's a safety signal.

📚 Part 4 · Making Charts Talk

Ticks — renaming the ruler

By default matplotlib numbers your axis 0, 1, 2, 3... plt.xticks() swaps those numbers for real-world labels like "Jan, Feb, Mar."

9

Turning index numbers into month names

import matplotlib.pyplot as plt

months = [0, 1, 2, 3]
sales = [120, 135, 150, 170]

plt.plot(months, sales, marker="o")
plt.xticks(months, ["Jan","Feb","Mar","Apr"])
plt.title("Monthly Sales")
plt.show()

print("X-axis now reads month names instead of 0,1,2,3")
>>> X-axis now reads month names instead of 0,1,2,3
  1. Data is stored as plain index numbers 0–3 — computers love these.
  2. plt.xticks(positions, labels) keeps the same positions but swaps the printed text.
  3. Without this step, a reader sees "2" on the axis and has to guess it means March.
  4. Same trick works vertically with plt.yticks().

Labels, titles & legends — the exit signs

An unlabeled chart is technically correct and practically useless — a room with no exit sign. The data's in there, nobody can find their way out.

10

Loop + label= — the standard pattern for many series

import matplotlib.pyplot as plt

months = ["Jan","Feb","Mar","Apr"]
regions = {
    "North": [100,120,115,130],
    "South": [90,95,105,110],
    "East":  [80,85,88,95],
}

for region, sales in regions.items():
    plt.plot(months, sales, marker="o", label=region)

plt.xlabel("Month", fontsize=12)
plt.ylabel("Sales (units)", fontsize=12)
plt.title("Regional Sales Comparison", fontsize=16)
plt.legend(title="Region", loc="upper left")
plt.show()

print("Plotted", len(regions), "regions with automatic legend")
>>> Plotted 3 regions with automatic legend
  1. Store multiple series in a dictionary — key is the region name, value is its sales list.
  2. Loop over regions.items(), plotting one line per region and giving each a label=.
  3. plt.legend() auto-collects every labeled line into one key box — no manual list needed.
  4. fontsize bumps text up so it's readable "from the back row" of a presentation.
VIBE CHECK

A legend is just the caption under a group photo telling you who's who — except matplotlib writes the caption for you, automatically, every single time.

  • The caption under a group photo tagging who's who.
  • A collaborative playlist cover with a small legend of contributing friends.
  • A broadcast graphic explaining what each jersey-number color means.
  • The little key on a campus map telling you which colored dot is the canteen.
11

Pushing a crowded legend outside the plot

import matplotlib.pyplot as plt

x = [1,2,3,4,5]
series = {f"Product {i}": [v*i for v in x] for i in range(1,6)}

for name, y in series.items():
    plt.plot(x, y, label=name)

plt.legend(bbox_to_anchor=(1.05,1), loc="upper left", ncol=1)
plt.title("Five Products, Legend Pushed Outside")
plt.tight_layout()
plt.show()

print("Legend moved outside the plot so it doesn't cover any lines")
>>> Legend moved outside the plot so it doesn't cover any lines
  1. A dictionary comprehension builds 5 product series in one line — y = x scaled by i.
  2. loc='best' would normally auto-place the legend — great until you have too many series and it starts covering data.
  3. bbox_to_anchor=(1.05, 1) anchors the legend just outside the top-right corner of the Axes.
  4. ncol= can also arrange entries into multiple columns to save vertical space.
📚 Part 4 · Making Charts Talk

Annotations — pointing at the story

plt.annotate() writes text AND draws an arrow to a specific point. It turns a plain chart into a chart that explains itself.

12

Flagging the exact day of a market crash

import matplotlib.pyplot as plt

days = list(range(60))
price = [200 + i for i in range(45)] + \
        [210 - (i*3) for i in range(15)]

plt.plot(days, price)
plt.annotate("Market Crash",
    xy=(45, price[45]), xytext=(30, 280),
    arrowprops=dict(facecolor="red", shrink=0.05))
plt.title("Stock Price Over Time")
plt.show()

print("Crash flagged at day 45, price:", price[45])
>>> Crash flagged at day 45, price: 210
  1. Prices rise steadily for 45 days, then drop sharply for 15 — a simple crash shape.
  2. xy= is the exact point being pointed at; xytext= is where the label text actually sits.
  3. arrowprops controls the arrow's color, width and shape.
  4. News sites do exactly this to mark the day a stock crashed or a company IPO'd.
VIBE CHECK

It's the little "this you?" arrow pointing at a screenshot — except pointing at the exact moment the market went sideways instead of an old tweet.

  • The "this you?" screenshot callout format, minus the roast.
  • A caption arrow pointing at the exact funny frame in a clip.
  • A news app circling the exact candlestick where a stock tanked.
  • A friend circling the one typo in your essay screenshot before sending it back.
13

Shading an "outlier zone" with a patch

import matplotlib.pyplot as plt
import matplotlib.patches as pt

x = [1,2,3,4,5,6,7]
y = [5,22,14,32,19,8,27]

fig, ax = plt.subplots()
ax.scatter(x, y, color="mediumpurple")

box = pt.Rectangle((2, 20), 3, 15,
        edgecolor="red", facecolor="red", alpha=0.2)
ax.add_patch(box)

ax.set_title("Highlighting the Outlier Zone")
plt.show()

print("Red zone highlights scores between x=2-5, y=20-35")
>>> Red zone highlights scores between x=2-5, y=20-35
  1. matplotlib.patches ships ready-made shapes: Circle, Rectangle, Polygon.
  2. Build the shape with its position and size, then attach it with ax.add_patch().
  3. alpha=0.2 keeps it translucent so the real data points stay visible underneath.
  4. A quality-control engineer uses this exact trick to flag a "high defect" region on a scatter plot without deleting any data.
QUICK RECAP

Ticks rename the ruler. Labels name the axes. Legends tell lines apart. Annotations point at the story. Patches let you highlight zones directly on the data.

📚 Part 5 · Save & Configure

Saving plots & setting global style

plt.savefig() exports the current figure as an image or document. rcParams sets defaults once so you never repeat styling code again.

14

Exporting a print-ready 300 DPI chart

import matplotlib.pyplot as plt

x = [1,2,3,4]
y = [10,25,18,30]

plt.plot(x, y)
plt.title("Final Report Chart")
plt.savefig("chart.png", dpi=300, bbox_inches="tight")

print("Saved chart.png at 300 DPI - ready for printing!")
>>> Saved chart.png at 300 DPI - ready for printing!
$ ls
chart.png
  1. Supported export formats: .png, .jpg, .pdf, .svg — pick whatever your report needs.
  2. dpi (dots per inch) controls sharpness — use 300 for anything getting printed.
  3. bbox_inches="tight" trims empty white space hugging the chart.
  4. A research paper or project report always needs a crisp, high-resolution export — not a blurry screenshot.
dpi = 72

Screen-only. Blurry, pixelated edges the moment it's printed or zoomed in.

dpi = 300

Print-ready. Crisp, sharp edges — safe for reports and posters.

Setting a company-wide chart style with rcParams

import matplotlib.pyplot as plt

plt.rcParams.update({

    "font.size": 12,
    "axes.facecolor": "#F6F5FB",
    "axes.grid": True,
    "grid.alpha": 0.3

>>> Global style set once - applies to every plot after this
  1. rcParams stores matplotlib's global default settings — figure size, font size, grid visibility and more.
  2. .update({...}) changes several settings at once with a plain dictionary.
  3. Every chart drawn after this point automatically picks up these defaults — no repeated styling code per cell.

📚 Part 6 · pandas.plot() — The Fast Lane

Why df.plot()?

pandas is built directly on top of matplotlib. Every DataFrame and Series carries a built-in .plot() method — no manually unpacking x and y.

VIBE CHECK

matplotlib is a manual-transmission car — full control, more pedals. pandas.plot() is the automatic version of the same engine — way less clutch work for a quick drive.

  • Editing a reel by hand in CapCut vs. hitting "auto-edit" for a quick version.
  • Manual pour-over coffee vs. an automatic machine — same beans, way less effort.
  • Typing a full search query vs. letting autocomplete finish your thought.
  • A manual gearbox vs. automatic — identical engine, very different amount of clutch work.

import pandas as pd

df = pd.DataFrame({
    "Month": ["Jan","Feb","Mar","Apr","May"],

})

df.plot(x="Month", y="Revenue", kind="line",

Bar plot — comparing branch-wise average marks

import pandas as pd

avg_marks = {
    "Chemical": 68, "Mechanical": 72, "EC": 75,
    "Electrical": 70, "Civil": 66
}

s = pd.Series(avg_marks)
s.plot(kind="bar", title="Avg Marks by Branch", color="mediumpurple")

print("Top branch:", s.idxmax(), "with", s.max(), "marks")
>>> Top branch: EC with 75 marks
  1. A plain Python dictionary becomes a pandas Series — keys become the index, values become the data.
  2. kind="bar" draws vertical bars; the X-axis is categorical (branch names), not continuous.
  3. Bar height instantly ranks the categories — no reading of numbers required.
  4. idxmax() returns the label of the largest value; max() returns the value itself.
VIBE CHECK

It's the "which friend group has the highest average CGPA" bar chart you'd absolutely make for the group chat, minus the drama.

GROUPED & HORIZONTAL BARS

Pass a DataFrame with multiple columns and pandas auto-groups the bars side by side. kind="barh" flips them horizontal (great for long labels), and stacked=True piles sub-categories into one total bar.

📚 Part 6 · pandas.plot() — The Fast Lane

Histograms & density plots

Both describe the shape of one numeric column — is it low, high, or bunched in the middle?

18

Histogram — sanity-checking an exam's marks

import pandas as pd
import numpy as np

np.random.seed(1)
marks = pd.Series(np.random.normal(65, 12, 60).clip(0,100).round())

marks.plot(kind="hist", bins=10,
           title="Marks Distribution", color="lightseagreen")

print("Class average:", round(marks.mean(),1))
print("Std deviation:", round(marks.std(),1))
>>> Class average: 65.3
>>> Std deviation: 11.8
  1. np.random.normal(65, 12, 60) simulates 60 exam marks centered around 65 with some spread.
  2. .clip(0,100) keeps marks inside a realistic 0–100 range; .round() makes them whole numbers.
  3. kind="hist" splits the marks into bins (buckets) and counts how many fall in each.
  4. A tall bar in the middle with thin tails = a fair exam; a lopsided shape hints the paper was too easy or too hard.

KDE — comparing two companies' salary curves

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(2)
companyA = pd.Series(np.random.normal(45000, 8000, 200))
companyB = pd.Series(np.random.normal(52000, 6000, 200))

companyA.plot(kind="kde", label="Company A")
companyB.plot(kind="kde", label="Company B")
plt.legend()
plt.title("Salary Density Comparison")
plt.show()

print("Company A median:", round(companyA.median()))
print("Company B median:", round(companyB.median()))
>>> Company A median: 44930
>>> Company B median: 51872
  1. kind="kde" (Kernel Density Estimate) draws a smoothed curve version of a histogram — no choppy "staircase" look.
  2. Plotting two Series on the same axes overlays their curves for a direct shape comparison.
  3. The curve's peak shows where values are most concentrated — easier to read than two sets of overlapping bars.
VIBE CHECK

It's basically two overlapping "vibe curves" — like comparing your sleep schedule vs your roommate's on one smooth graph instead of two jagged bar charts fighting for space.

  • Weekday vs. weekend screen-time density, overlaid on the same graph.
  • Two exam batches' score curves overlaid to argue which paper was "easier."
QUICK RECAP

Line = trend. Bar = comparison. Histogram = distribution. KDE = smoothed distribution. Scatter = relationship. All five are one line away with df.plot(kind=...).

Study hours vs exam score — checking a hunch

import pandas as pd

df = pd.DataFrame({
    "StudyHours": [1,2,3,4,5,6,7,8],
    "ExamScore":  [40,45,55,60,68,75,82,90]
})

df.plot(kind="scatter", x="StudyHours", y="ExamScore",
        title="Study Hours vs Exam Score", color="crimson")

correlation = df["StudyHours"].corr(df["ExamScore"])
print("Correlation coefficient:", round(correlation, 3))
>>> Correlation coefficient: 0.997
  1. kind="scatter" needs both an x= and a y= numeric column — every row becomes one dot.
  2. An upward-drifting cloud of points visually confirms the relationship before writing a single formula.
  3. .corr() turns that visual hunch into one precise number between -1 and 1.
  4. A tight diagonal cloud (like here) means strong correlation; a wide scattered cloud means weak or none.

🎓 Before You Plot

Common mistakes & best practices

AVOID
🙈

Skipping labels — forces the reader to guess the units.

🌈

Color overload — ten random colors confuse more than they clarify.

🍕

Wrong chart type — a line chart for unordered categories hides the story.

📉

Low-res exports — always savefig(dpi=300), never a screenshot.

DO INSTEAD
✏️

Start simple — sketch with pyplot first, switch to OO for multiple subplots.

🏷️

Label everything — title, X-axis, Y-axis, legend, every time.

🎯

Pick colors with intent — let color encode meaning, not decoration.

🖨️

Test in black & white — if it's unreadable, add markers/linestyles.

🎁 Key takeaways

  • A Figure holds one or more Axes — build dashboards with plt.subplots().
  • Color, marker & linestyle are a visual language — use them with intent.
  • Ticks, labels, legends and annotations turn a chart into a self-explaining story.
  • rcParams and savefig() make your styling consistent and report-ready.
  • pandas' .plot() is matplotlib in automatic mode — one line, five chart types.
  • Every dataset today — sales, sensors, exams, Titanic — used the SAME five tools.
